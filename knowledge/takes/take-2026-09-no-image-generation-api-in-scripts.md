# No script in the pipeline may call an image-generation API

Every image in the CVG content machine — blog posts, error-library posts, Pinterest pins — is
generated by hand by Dimu. A script's job stops at writing the prompt and the expected filename,
then waiting for the file to appear.

> VERBATIM: "**Never call an image-generation API (Gemini/Nano Banana or otherwise) from a script.** All images — blog posts, error posts, Pinterest pins — are Dimu's to generate by hand from the prompts a script writes to `image-gallery/<batch>/image-prompts.md`. A script's job stops at writing the prompt + expected filename and waiting for the file to appear."

The rule has an origin. The Pinterest pin pipeline (built 2026-07-20/21) first called Gemini
directly, and was shut down on 2026-07-21:

> VERBATIM: "the pipeline originally called Gemini (\"Nano Banana\") directly to generate pin images — Dimu shut this down (Golden Rule 10) after it hit a Gemini billing wall (`limit: 0` free-tier quota on every current image model)."

It was rebuilt on the write-the-prompt-and-wait pattern the blog and error-post images already
used: a generator writes prompts plus metadata sidecars, Dimu drops the finished images in, and a
watcher script picks up whatever has arrived without waiting for the full set.
