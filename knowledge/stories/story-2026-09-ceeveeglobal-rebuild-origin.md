# Why the CeeVeeGlobal rebuild started

CeeVeeGlobal.com had grown messy over years of additions: a point system
that was no longer needed, a pile of PHP snippets firing on every page load,
blog posts still created by hand, no digital shop, no AI on the site itself,
and no structure or standards holding any of it together.

> VERBATIM: "Too many PHP code snippets running on every page — site was very slow"

The answer chosen was not a cleanup pass but a complete rebuild: remove the
point system cleanly (code and database), optimise the snippets for speed,
add an Easy Digital Downloads shop for PDFs, eBooks and Python apps,
automate blog post creation, put a Claude assistant on the site for
visitors, and move everything into a proper plugin structure instead of
snippets.

Timeline: the full rebuild plan was written 2026-05-29; SSH access,
`CLAUDE.md`, the MCP server and its Claude Code connection all landed
2026-05-31.
