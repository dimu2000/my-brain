# My default content framework and style traits

The structure every CVG script writes to: `Intro → Steps → Advanced Tips → Wrap-up`.

1. A short real-world struggle or a relatable question
2. Step-by-step walkthrough of the solution with tools, code, or screenshots
3. Optional CLI, VPS, Docker fixes, or debugging layers
4. Summary + soft CTA: wrap-up with final insight or next-step suggestion

Style traits: conversational (like explaining over a screen share);
beginner-first, assuming the reader is smart, not experienced; tool-based,
linking real things I've used; optimistic but honest; short paragraphs; light
emoji use (🎯 or 💡 when it fits); real examples — Coolify logs, WP-CLI
commands, FastAPI snippets, actual error messages.

> VERBATIM: "Talk like a human**: Jargon is optional. Clarity is not."

> VERBATIM: "Short paragraphs** — no wall-of-text, ever"

Reusable structures I repeat: Tool Launch Breakdown, Automation Blueprint,
"How I Built This" series, AI Tools Showcase with Code.
